# Workflow Editor Frontend

Редактор рабочих процессов на Vue3 + Pinia + TypeScript

## Установка зависимостей

```bash
cd frontend
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:5173

## Сборка для продакшена

```bash
npm run build
```

## Запуск тестов

### Unit-тесты (Vitest)

```bash
npm run test:run
```

### E2E-тесты (Cypress)

```bash
npm run cy:open
```

## Функциональность

- Таблица шагов рабочего процесса с возможностью добавления, удаления и редактирования
- Диаграмма с визуализацией шагов и связей между ними
- Перетаскивание блоков на диаграмме (drag-and-drop)
- Выделение шагов при клике в таблице или на диаграмме
- Поиск и фильтрация шагов
- Сортировка с сохранением в localStorage
- Зум диаграммы колесиком мыши и кнопками

## Структура проекта

```
src/
  ├── components/
  │   ├── StepTable.vue      # Компонент таблицы шагов
  │   └── DiagramView.vue    # Компонент диаграммы
  ├── stores/
  │   ├── workflow.ts        # Pinia store для управления состоянием
  │   └── __tests__/
  │       └── workflow.spec.ts # Unit-тесты
  ├── App.vue                # Главный компонент
  ├── main.ts                # Точка входа
  └── style.css              # Глобальные стили
```
