Реализованы все Обязательные требования.

Из необязательных:
- Можно удалить шаг рабочего процесса в таблице по нажатию на иконку корзины, удаления с запросом на backend
- Изменение зума на диаграмме скроллом мышки и нажатии на кнопки
- Перетаскивать полотно зажатием кнопки мыши

Технология: 
- TypeScript
- Vue3
- Pinia 
- Scss (модульный) 
- Cypress
- Vitest
- Canvas = Диаграмма

Особенности проекта по тестовому заданию:
- Изменения название проиисходит при двойном клике на нём, при нажатие Enter или потери фокуса, слхраняются изменения в backend
- Исправлены кординаты "Возврат" x, y были поменяны местами в backend, так соответвует макету
- Напраление стрелок от центра одного блока по наравлению к другому, так алгоритм предсказуемый, при изменении названия, стрелка адаптируется
- При создании блок белый, он сливается с цветом фона и его не видно, но он создаётся и появляется, при нажатии в таблице на него он выделиться в диаграмме
